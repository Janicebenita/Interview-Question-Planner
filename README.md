# Interview Question Planner

An HR agent that converts job competencies into a structured and consistent interview plan.

## Workflow

1. Read the role, competencies, seniority, and interview duration.
2. Select job-relevant question types.
3. Generate questions, probes, and evidence indicators.
4. Submit the plan for recruiter approval.

## Passport Files

The root folder contains `agent.yaml`, `SOUL.md`, and `EXPLAINABILITY.md`.
